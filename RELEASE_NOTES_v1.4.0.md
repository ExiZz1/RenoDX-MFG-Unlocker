# RenoDX MFG Unlocker v1.4.0

- Search MFG Settings across categories. Filter by upstream source, pending changes, editability or favorites.
- Save and preview local settings profiles, import and export JSON, and stage documented defaults. Restore through authenticated transactions and review the files affected.
- Run the reviewed official ReShade Setup after acknowledging possible third-party proxy conflicts. RenoDX verifies the package and rescans after confirmed setup completion.
- Export a redacted diagnostic report that distinguishes installed components and verified backups. Runtime activity still depends on live evidence.
- Fixed a WPF dropdown crash and improved recovery presentation across English, Ukrainian, Polish, German, Spanish, French, Czech and Brazilian Portuguese.
